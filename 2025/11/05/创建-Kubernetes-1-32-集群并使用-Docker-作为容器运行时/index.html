0x05 安装 Dockershim

随着时间的推移，Kubernetes 创建了 CRI 接口，允许用户接入不同的运行时环境，从而使 Kubernetes 逐渐演变成一个与容器无关的平台。

Docker Engine 是一个比 Kubernetes 更早的项目，并未实现 CRI。为了弥合新旧技术之间的差距，Kubernetes 引入了一个名为 dockershim 的组件，使 Kubernetes 能够使用 Docker 作为运行时来执行容器。然而，从 Kubernetes 1.24 版本开始，dockershim 组件被完全移除，因此 Kubernetes 不再原生支持 Docker 作为运行时。
